# Website

The website of `bt serve`: Preact views in `src/<folder>/*.tsx`, rules and
data access in `src/*.ts`, the request and reply types in `src/api/`
(generated by `cargo test`; do not edit them), and the style files in
`styles/`. Every number comes from the server.

Run these in `web/`:

- `npm ci` installs the dependencies.
- `npm run check` checks the types.
- `npm test` runs the rule tests (`src/*.test.ts`) with `node --test`.
- `npm run build` writes the site to `dist/`: `index.html` (Build strategy,
  Runs & saved, Result review) and `data.html` (the data page).

## Browser checks

`npx playwright test` runs `e2e/*.spec.ts` in Chromium. It needs
`npm run build`, `cargo build -p bt` (from the repository root), and once
the browser itself: `npx playwright install chromium`. Each
worker makes its own home from the fictional data in a temporary folder
(`TMPDIR`), prepares it and starts `bt serve --port 0` on it
(`e2e/fixture.ts`). A long run (`addLongRun`) writes about 0.5 GB there
while it runs, so set `TMPDIR` to a larger folder if `/tmp` is small.

## Serving a home's website

`bt serve --home H` serves the folder `H/web/` at `/`. Link it to the build
while you work on the site, then reload the page after each build:

    ln -s "$PWD/dist" H/web
    bt serve --home H --port 3001

or copy `dist/` to `H/web/`.
