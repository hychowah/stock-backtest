# Exact authoring content

## Context

Slice 1 qualifies expanded captures, but the editor exposes four inputs.
The measure owner has 33 exact bundles. Submitted measure dependencies validate
and apply, while library admission/reopening assume archived dependencies.
Users need discoverable terms that survive Save and exact reopening.

## Options and choice

Separate parameter lists, special measure Save handling and browser formulas
repeat meaning and resolution. Choose owner-produced authoring descriptors and
one exact-content resolution boundary.

`variable_authoring.py` projects 52 direct descriptors, separate policy adapters
and 33 measures from existing owners. It supplies categories, descriptions,
units, supported history and exact insertion content. Recognition, qualification,
backend support, installed readiness and observed availability stay distinct.

`measures.py` supplies exact immutable lookup. The library resolves submitted
content first, checked archive rows second, and an absent archive reference
through a matching measure identity/revision. Other absent references fail.
Archive corruption remains visible. Registry lookup never imports durable
entries. Captures embed registry definitions with existing submitted provenance.
Authored reopening uses owner labels. Detached restoration reads no registry.

The workspace consumes descriptors for search, categories and details. Measures
insert exact reference terms and complete reachable content. New definitions use
version 3/catalog `/3`. Old definitions retain their namespace until an explicit
expanded-input upgrade. Supported history comes from owners; quarterly, TTM and
calendar statistics remain absent.

## Ownership and protected contracts

Allowed seams: measure lookup; library resolution/admission/capture/authored
projection; financial-free authoring catalog/content; variable HTTP composition;
workspace JavaScript, HTML and CSS. StrategyDraft remains authoritative. A draft
change requires a demonstrated interface defect.

Preserve formulas, schemas, immutable formats, revisions, labels, archive
integrity, old bytes and the 32-definition ceiling. Keep revision/generation
race guards, held queue edits and explicit Apply. Editing, validation, preview,
Save and Apply start no backtest.

## Consequences

All 33 measures must pass Validate, Save, exact reopening and capture. Cover
dependent/repeated terms, unknown revisions, damaged archives, ordinary missing
or deleted dependencies, no automatic imports and registry-free detached replay.
Actual desktop/mobile/keyboard checks must exercise discovery, history, explicit
upgrade and focus return.
