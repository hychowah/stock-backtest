# Complete recorded-scope coverage

Superseded by the [typed-storage summary](../../../../typed-storage/master-plan.md):
coverage discovers only the open book's pools, reports no provider admission
counts and reserves no work. The current contract is in the
[variable design](../../../variable-design.md).

## Context

Preview evaluates 1–16 named roots. Phase 11 needs separate bounded inspection
by generation, date and pool, without return books or truncated success.

## Options and choice

Extending preview to enumerate symbols mixes meanings and repeats population
and planning rules. Choose one application coverage owner using shared complete
scope planning and reference evaluation.

`variable_coverage.py` discovers recorded January/latest scopes, including empty
scopes. Inspection requires the discovered generation and exact scope identity.
Absent/changed scopes fail. Arbitrary fixed/random root construction is excluded;
those execution modes remain qualified separately. Formula `at`/`lookback`
contexts retain dated owner policy.

The denominator is every snapshot row in the selected recorded date/pool before
availability, ranking, filters and rank ranges, with no metric-availability join.
Empty scopes report zero and no percentage. Each captured output reports valid
and unavailable counts and deterministic reason counts. Provider admission
failures stay separate. Result reasons are the recorded first unavailable reason,
not every missing ingredient. Bind generation, projection, scope and program.

`scalar_execution.py` owns shared complete population reading, duplicate/size
checks, prepared root identities, qualification, adaptive chunks and aggregate
reservations. Extract the existing interface rather than copy planning/budgets.
Reserve tasks, inspected rows, scopes, metadata and output before observation.
Preserve ceilings; over-budget requests fail with `WORK_LIMIT`. Coverage reduces
and discards blocks. Selection retains ranking, filters, results and evidence.

## Ownership and protected contracts

Allowed seams: shared scope planning; new application coverage owner; narrow
methods beside preview in Original/selectable calculations; routes beside preview
in `website/server/backtests.py`; workspace coverage presentation.

Reuse experimental parent-operation admission, Original financial ownership,
readiness, daily/research connections and borrowed prepared views. Close them
before reply. Preserve freshness, full content checks, disconnect cancellation
and lock ordering. Require same-origin finite bounded requests with exact fields.
Cancel superseded browser inspection and ignore stale replies. Label Original
reference inspection explicitly.

Change no provider, formula, schema, numerical preview, codec or durable store.
Recorded roots use stored owner lanes; derived contexts use dated policy even on
equal dates. Missing prepared lanes never fall back.

## Consequences

Verify both pools/modes, complete denominators, empty/missing lanes, history,
constants, stale/absent/malformed requests, byte/work limits, cancellation,
cleanup, narrow reads and no SQL writes/jobs. Compare affected selection and
both-engine evidence after extraction. Actual browser checks distinguish sample,
coverage, qualification and readiness. Synthetic checks establish no installed
readiness or live-cache claim.
