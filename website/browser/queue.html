How this works

To add a test, select Historical backtest in Build strategy, set the steps and dates, then select Add to queue. Change the settings to add the next test.

Pause queue prevents the next test from starting; the active test can finish. Saved backtests has 100 slots. If saving fails or all slots are used, the complete result stays in In progress while the server retries. Failed and stopped tests remain there. After a server restart, an interrupted test runs again with the same random date set.

Select the name of a saved backtest to open its result. Details in a row shows the settings of that test and its other actions; Tune copies the settings to Build strategy. Tick saved backtests, then select Compare or Delete ticked; the box in the heading ticks every row shown. Details and the comparison read stored results and run no test.

CAGR is the mean trial CAGR for random dates. Select the Name, CAGR or Saved heading to sort the saved backtests.
