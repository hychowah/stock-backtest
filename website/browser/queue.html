How this works

Select Add to queue beside Run backtest in Build strategy. From latest mode, the first click opens the dated backtest settings and turns off Auto-run without starting a test. Choose fixed or random dates, adjust the settings, then select Add to queue again. You can type a test name in the box beside it. An empty name describes the final Rank, then the other steps; it adds the rebalance interval when that is not 12 months, and the market when that is not US. The line below those buttons shows the result of Add to queue and of a held edit. Change the settings to add the next test. Adding, tuning or editing a queued test turns off Auto-run so parameter changes stay manual. Tests run one at a time. You can close this page. Keep the server computer awake and its terminal open.

Pause prevents the next test from starting. The active test can finish. A completed test moves to Finished automatically. Finished shows the saved library, which has 100 slots. If saving fails or all slots are used, the complete result stays in In progress while the server retries. Failed and stopped tests remain there. An interrupted test retries with the same random date set after server restart. Held edits stay held.

Select the name of a finished test to open its result. Select ⋯ in a row for its other actions. Tune copies the settings of a test to Build strategy. Tick finished tests to compare them: the settings that differ show first, then the headline of each test. One tick shows the headline, the settings and the saved ID of that test. You can tick 8 tests at most. Clear in the panel removes every tick. The comparison reads stored results and runs no test.

CAGR is the mean trial CAGR for random dates. Test types and date windows can differ. Select the Name, CAGR or Saved heading to sort the finished tests. A missing CAGR stays last.
