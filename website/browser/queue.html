How this works

Every dated test runs from this queue. In Build strategy, select Historical backtest, choose fixed or random dates, adjust the settings, then select Add to queue. You can type a test name in the box beside it. An empty name describes the final Rank, then the other steps; it adds the rebalance interval when that is not 12 months, and the market when that is not US. The line below those buttons shows the result of Add to queue and of a held edit. Change the settings to add the next test. Tests run one at a time. You can close this page. Keep the server computer awake and its terminal open.

Pause prevents the next test from starting. The active test can finish. A completed test moves to Saved backtests automatically. Saved backtests has 100 slots. If saving fails or all slots are used, the complete result stays in In progress while the server retries. Failed and stopped tests remain there. An interrupted test retries with the same random date set after server restart. Held edits stay held.

Select the name of a saved backtest to open its result. Select Details in a row to read the settings of that test in place and to find its other actions. Tune copies the settings of a test to Build strategy. Tick two or more saved backtests to compare them: the settings that differ show first, then the headline of each test. You can tick 8 tests at most. Clear in the panel removes every tick. Details and the comparison read stored results and run no test.

CAGR is the mean trial CAGR for random dates. Test types and date windows can differ. Select the Name, CAGR or Saved heading to sort the saved backtests. A missing CAGR stays last.
