Data to check

Include earlier prices for report-date valuations and trailing return filters. A 3-year return filter needs three years of prior prices. The original candidate group uses the existing January rules and latest saved SPY session. The broad group can require thousands of additional stock histories.

Data types to download if missing

Annual financials fill missing symbols across the saved universe, or only your specific symbols. Full annual financial data uses the chosen stock group. All returned fields, null values, currencies and filing metadata are saved. Existing trimmed key metrics can be backfilled in the separate full-data cache. Existing financial records and the saved universe are reused. This action does not refresh existing company profiles or annual reports.

Downloads use up to 32 parallel requests and save completed windows as they finish. Cancel stops new requests and keeps saved work. Active requests may take a short time to stop.

Connecting to the local data service…

Downloads use your FMP subscription. The key stays in ~/.grok/secrets/fmp_api_key. The page never receives the key. No downloads start when this panel opens.

Metric availability

EV/EBITDA, 3-year average EBITDA, market cap, EV and trailing returns use the current cache. P/E, P/B, free cash flow, net profit margin, PEG, ROE, current ratio, interest coverage and debt/equity require the extra annual statements. Select Full annual financial data to save complete responses for annual income statements, balance sheets, cash flow statements, key metrics and ratios for the chosen stock group. Rebuild prepared data after downloading. Missing values exclude a stock only when a filter needs them.

“Checked range” means that the saved date span or prior successful requests cover the selected range. It does not promise a price on every session. A new listing or trading stop can leave a short or empty history. Empty provider responses are recorded against the saved file contents, so retrying does not repeatedly request the same unavailable dates. If a file is lost, damaged or replaced, its old completion record is not reused. The download fills unrequested dates outside an imported saved span. It also resumes unfinished managed windows inside an expanded span. It does not infer missing sessions inside older imported data.

Raw files and prepared outputs stay on this computer. Expanded holdings can include early trading stops that have not received the original bankruptcy review.
